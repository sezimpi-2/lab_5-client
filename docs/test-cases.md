
# Тестирование React-клиента

## 1. Проверка CRUD

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Просмотр студентов | Список студентов отображается |
| 2 | Добавление студента | Новая запись появляется в списке |
| 3 | Редактирование студента | Данные обновляются |
| 4 | Удаление студента | Запись удаляется из списка |

## 2. Проверка пагинации

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Открытие первой страницы | Отображаются первые записи |
| 2 | Нажатие «Вперёд» | Открывается следующая страница |
| 3 | Нажатие «Назад» | Открывается предыдущая страница |
| 4 | Последняя страница | Кнопка «Вперёд» неактивна |

## 3. Проверка маршрутов

| Маршрут | Ожидаемый результат |
|---|---|
| / | Перенаправление на /students |
| /students | Список студентов |
| /students/new | Форма добавления |
| /students/:id/edit | Форма редактирования |
| /test | Страница 404 |

## 4. Проверка ошибок

- Остановка сервера: отображается сообщение об отсутствии соединения.
- Пустые поля формы: отправка блокируется.
- Несуществующий ID: отображается ошибка.
- Неверный формат ответа: API возвращает ошибку проверки данных.

## 5. Проверка сборки

Команда: npm run build

Ожидаемый результат: сборка завершается без ошибок.
