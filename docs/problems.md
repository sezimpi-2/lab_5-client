
# Журнал проблем и работы с ИИ

## Часть 1. Проблемы, возникшие при разработке

Во время выполнения лабораторной работы №5 возникли следующие проблемы.

| № | Проблема | Причина | Решение |
|---|---|---|---|
| 1 | Failed to connect to localhost:5000 | REST API сервер Lab 2 не был запущен | Перешли в папку lab_2_Sezim и запустили node server/index.js |
| 2 | Cannot find module './pages/StudentsPage' | В названии файла StudentsPage.tsx был лишний пробел в начале | Переименовали файл и исправили путь импорта |
| 3 | Property 'error' does not exist on type Result | TypeScript не определял нужную ветку объединённого типа | Использовали проверку if ("error" in result) |
| 4 | Пагинация отображала только одну страницу | На странице было два студента, а лимит составлял пять записей | Временно установили limit = 1 и проверили переключение страниц |
| 5 | После настройки React Router пропало оформление | Стили App.css перестали подключаться глобально | Подключили App.css в main.tsx |
| 6 | Изменения интерфейса не отображались в браузере | Браузер использовал предыдущую версию стилей | Сохранили файлы и обновили страницу |

## Часть 2. Использование ИИ-ассистента

### Случай 1. Создание React-клиента

**Промпт:**

Помоги разработать React-клиент на TypeScript для REST API. Необходимо реализовать список студентов, добавление, редактирование, удаление и обработку ошибок.

**Ответ ИИ:**

Были предложены структура React-проекта, типы TypeScript, API-клиент, собственный хук useStudents и компоненты для работы со студентами.

**Что было проверено:**

- Запуск проекта через npm run dev.
- Сборка через npm run build.
- Получение студентов через GET.
- Добавление через POST.
- Редактирование через PUT.
- Удаление через DELETE.

**Результат:**

Предложенный код был адаптирован к существующему REST API и проверен запуском приложения и выполнением операций CRUD.

### Случай 2. Исправление ошибок TypeScript и маршрутизации

**Промпт:**

Проверь мой React-код и помоги исправить ошибки TypeScript, связанные с типом Result, импортами компонентов и React Router.

**Ответ ИИ:**

Были предложены исправления объединённого типа Result, проверки ошибок через Type Guards, правильного расположения файлов и настройки React Router.

**Что было проверено:**

- Проверка типов командой npm run build.
- Поиск файлов через команду ls src/pages.
- Проверка импортов компонентов.
- Проверка маршрутов в браузере.
- Проверка переходов между страницами.

**Результат:**

Было обнаружено лишнее пространство в названии StudentsPage.tsx. После переименования файла сборка прошла успешно. Также были настроены отдельные маршруты для списка, добавления и редактирования студентов.

## Заключение

В ходе лабораторной работы были изучены возможности React, TypeScript и REST API. Использование ИИ-ассистента помогло разобраться с ошибками, улучшить структуру проекта и реализовать основные функции управления студентами.

Все предложенные изменения проверялись с помощью сборки проекта и тестирования приложения в браузере.
