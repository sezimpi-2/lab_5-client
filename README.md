
# Информационная система университета

## Описание проекта

Лабораторная работа №5 по дисциплине «Разработка клиент-серверных приложений».

Проект представляет собой React-клиент для управления студентами университета через REST API.

Приложение позволяет просматривать список студентов, добавлять новых студентов, редактировать существующие записи и удалять их.

## Используемые технологии

- React
- TypeScript
- Vite
- React Router DOM
- REST API
- Node.js
- Express.js
- CSS

## Функциональные возможности

1. Просмотр списка студентов.
2. Добавление нового студента.
3. Редактирование информации о студенте.
4. Удаление студента.
5. Пагинация списка студентов.
6. Обработка ошибок сервера.
7. Проверка структуры полученных данных с помощью Type Guards.
8. Использование Result<T> для обработки результатов API.
9. Отмена устаревших запросов с помощью AbortController.
10. Навигация между страницами через React Router.
11. Страница 404 для неизвестных адресов.

## Установка и запуск

### 1. Запуск REST API (Lab 2)

Откройте первое окно терминала:

```bash
cd ~/PycharmProjects/lab_2_Sezim
```

Установите зависимости, если они ещё не установлены:

```bash
npm install
```

Запустите сервер:

```bash
node server/index.js
```

Сервер будет доступен по адресу:

http://localhost:5000

### 2. Запуск React-клиента (Lab 5)

Откройте второе окно терминала:

```bash
cd ~/PycharmProjects/lab5-client
```

Установите зависимости:

```bash
npm install
```

Запустите клиент:

```bash
npm run dev
```

Приложение будет доступно по адресу:

http://localhost:5173

### 3. Проверка production-сборки

```bash
npm run build
```

## Маршруты приложения

| Маршрут | Назначение |
|---|---|
| / | Перенаправление на список студентов |
| /students | Реестр студентов |
| /students/new | Добавление студента |
| /students/:id/edit | Редактирование студента |
| * | Страница 404 |

## REST API

Базовый адрес:

http://localhost:5000/api/v1

Основные запросы:

| Метод | Маршрут | Описание |
|---|---|---|
| GET | /students | Получение списка студентов |
| GET | /students/:id | Получение студента по ID |
| POST | /students | Добавление студента |
| PUT | /students/:id | Редактирование студента |
| DELETE | /students/:id | Удаление студента |
